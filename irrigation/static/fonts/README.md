# Font Files

Place the following font files in this directory:

1. **VIP-RAWY-REGULAR.TFF** - Arabic font (required)
2. **Comfortaa-Regular.ttf** - English font (download from Google Fonts if not using CDN)

The CSS references these via `@font-face` in `static/css/app.css`.
If the actual font files are missing, the app will fall back to system fonts automatically.
